# Groundwork Agent

A modular Retrieval-Augmented Generation (RAG) agent built with **LlamaIndex**, **ChromaDB**, **LangChain**, and later **LangGraph**.

The goal is to create a production-ready RAG pipeline with:

- Incremental document ingestion
- Metadata-aware retrieval
- Source citation validation
- Modular generation pipeline
- LangGraph workflow orchestration
- FastAPI backend
